# NEON CLASH v3.3.0

## Web release

This release is a standalone browser build. Extract `neon-clash-v3.3.0-web.zip` and open `index.html`, or serve the extracted folder with a local HTTP server for the best PWA, audio, gamepad, and fullscreen compatibility.

## Controls

- Player 1: `A`/`D` move, `W` jump, `S` block, `J` punch, `K` kick, `L` power, `U` special, `I` dash.
- Player 2: Arrow keys move/block/jump, `1` punch, `2` kick, `3` power, `4` special, `5` dash.
- Gamepads, touchscreen controls, and mouse controls are supported.

## Included

- 8 playable fighters
- Arena, Training, Versus, and Survival modes
- PWA/offline support
